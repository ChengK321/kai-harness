# Kai V1.0-D1 Capability Binding Design

状态：Design

## 定位

Capability Binding 用于关联已有能力，不创建新的执行层。

## 数据关系

```text
Environment
    |
    +---- Capability Reference
                |
                +---- Existing Tool / MCP / Service
```

## Kai 负责

- 能力身份关联
- 使用范围描述
- 治理验证引用

## Kai 不负责

- 工具发现市场
- 工具执行
- 参数编排
- 重试恢复

## 验证目标

证明 Kai 可以安全描述“可以使用什么能力”，而不是“如何执行能力”。
