# Kai V0.9-D1 Environment Registry Freeze Checklist

状态：D1 Freeze Preparation

## 1. 目标

本阶段冻结 Environment Registry 的最小控制面边界，确认 Registry 不演变为执行平台、配置中心或权限系统。

核心定位：

```
Environment Identity
        +
Capability Declaration
        +
Reference Lookup
```

## 2. 架构边界检查

### Registry 负责

- 环境唯一标识
- 环境类型声明
- 信任等级声明
- 能力引用声明
- 基础格式校验

### Registry 不负责

```
❌ Authentication
❌ Authorization
❌ Secret Storage
❌ Command Execution
❌ Workflow Scheduling
❌ Observation Collection
❌ Policy Decision
```

## 3. 与现有 Control Plane 集成边界

```
              Kai Control Plane

+-----------------------------+
| Environment Registry        |
|                             |
| identity / capability       |
+-----------------------------+

              |
              v

+-----------------------------+
| Observation Provider        |
| readonly state collection   |
+-----------------------------+

              |
              v

+-----------------------------+
| Governance Validator        |
| contract checking           |
+-----------------------------+
```

Registry 提供环境事实，不决定动作。

## 4. Anti-Overengineering Review

检查项：

| 项目 | 结果 |
| --- | --- |
| 是否引入数据库职责 | 否 |
| 是否保存密钥 | 否 |
| 是否复制 IAM | 否 |
| 是否创建 Executor | 否 |
| 是否替代 MCP | 否 |
| 是否成为 Workflow Engine | 否 |
