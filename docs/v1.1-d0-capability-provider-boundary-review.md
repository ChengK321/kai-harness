# Kai V1.1-D0 Capability Provider Boundary Review

Status: Design Proposal

## Goal

Define how Kai connects external capabilities without becoming an execution platform.

## Boundary

```text
Kai Control Plane
        |
        v
Capability Reference
        |
        v
Capability Provider
        |
        v
Environment
```

## Capability Provider Responsibilities

The provider owns:

- Domain operation execution.
- Execution evidence generation.
- Environment-specific integration.

Kai owns:

- Identity binding.
- Governance validation.
- Evidence association.

## First Prototype Scope

Readonly capability only:

```yaml
capability:
  - service.status.read
  - health.check.read
```

## Explicit Non Goals

Do not introduce:

- SSH executor.
- Shell gateway.
- Workflow engine.
- Auto remediation.
- Generic tool protocol.

## Evolution Path

1. Readonly capability provider.
2. Capability binding verification.
3. Verification integration.
4. Controlled action evaluation only after boundary review.
