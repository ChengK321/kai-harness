# Kai V0.9-D3.4 Capability Governance Binding

Status: Proposed

## Relationship

Capability describes what an environment can provide.
Governance decides whether a requested intent may reference that capability.

Capability != Permission
Capability != Approval
Capability != Execution

## Flow

Observation
 |
 v
 Agent Intent
 |
 v
 Governance Validator
 |
 v
 Capability Reference
 |
 v
 Existing Provider

## Constraints

No automatic action selection. No executor creation. No workflow orchestration.
