## Release Criteria

- Observation boundary remains read-only.
- Governance validates constraints but does not execute actions.
- Capability Reference does not contain execution logic.
- Verification is independent from execution evidence.
- No Executor, Workflow Engine, SSH Manager, or Auto Recovery Loop is introduced.
