# Kai V1.0 Controlled Prototype Scope Freeze

状态：Proposed / D0 Scope Freeze

## 1. Purpose

V1.0 不扩展 Kai 为完整 AI 平台，而是验证 V0.6-V0.9 Control Plane 架构是否能够安全连接真实环境。

核心闭环：

```text
Observation
    |
    v
Governance Intent
    |
    v
Validation
    |
    v
Existing Capability
    |
    v
Execution Evidence
    |
    v
Observation Verification
```

## 2. Prototype Scenario

首个验证场景：VPS Service Recovery。

用户请求：网站异常，需要恢复服务。

验证重点：
- Agent 可以提出建议；
- Kai 可以关联环境身份；
- Governance 可以约束动作边界；
- 已有工具负责实际执行；
- Observation 验证结果。

## 3. Architecture Boundary

Kai 保留：

- Environment Identity
- Observation Reference
- Capability Reference
- Governance Validation
- Evidence Association

Kai 不实现：

- Agent Runtime
- Workflow Engine
- Executor
- SSH Manager
- MCP Protocol
- Auto Recovery Loop

## 4. Data Flow

```text
User
 |
 v
External Agent
 |
 v
Governed Intent
 |
 v
Kai Validation
 |
 v
Existing Tool / MCP
 |
 v
Environment
 |
 v
Verification Observation
```

## 5. Success Criteria

V1.0 成功标准不是自动运维，而是证明：

Kai 能够让 Agent 在不直接拥有环境控制权的情况下，安全关联真实环境能力。

所有扩展必须继续满足 V0.6-V0.9 架构边界。
