# Kai V1.0-D1 Environment Instance Design

状态：Design

## 目标

建立真实环境接入前的最小 Environment Instance 抽象，不实现执行能力。

## 边界

Environment Instance 只描述：

- 环境身份
- 能力引用
- Observation 来源
- Governance 约束

不包含：

- SSH 执行
- Shell 命令
- 服务管理
- 自动恢复

## 模型

```text
Environment Instance
        |
        +-- Identity
        |
        +-- Capability Reference
        |
        +-- Observation Reference
        |
        +-- Governance Constraint
```

## 原则

Kai 保存环境关系，不拥有环境控制权。
