# Kai V1.1-D9 Integration Test Design

Status: Design

## Goal

验证 Minimal Capability Adapter 是否能够在不引入执行层的情况下完成：

Environment → Observation → Adapter → Capability Reference → Verification 的闭环。

## Test Flow

```text
Environment
     |
     v
Existing Observer
     |
     v
Observation Evidence
     |
     v
Minimal Capability Adapter
     |
     v
Capability Reference
     |
     v
Verification Contract
     |
     v
Verified Result
```

## Test Scope

Included:

- service.status.read
- health.check.read
- evidence mapping
- verification association

Excluded:

- restart service
- shell execution
- SSH access
- workflow orchestration
- automatic remediation

## Acceptance Criteria

1. Observation 数据能够关联正确 environment identity。
2. Capability Reference 不包含执行细节。
3. Verification Result 不直接信任 Provider 返回值。
4. Failure 状态保持 unknown/failed，不自动触发动作。

## Boundary

Kai 仍然只负责治理和关联，不拥有环境控制权。
