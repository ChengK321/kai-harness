# Kai V0.9 Environment Registry Minimal Design

状态：Proposed / V0.9-D1 / Design Only

## 1. 定位

Environment Registry 是 Kai Control Plane 的环境身份与能力声明索引。

它不等于 CMDB、资产管理平台、部署平台或权限系统。

核心问题：

> Kai 是否知道一个环境是什么，以及该环境允许关联哪些能力。

## 2. 架构位置

```text
External Agent
      |
      v
Governance Intent
      |
      v
Kai Control Plane
      |
      +----------------+
      | Environment    |
      | Registry       |
      +----------------+
      |
      v
Observation Provider / Existing Tool / MCP
      |
      v
Environment
```

## 3. Registry 负责

- environment_id 唯一标识
- environment_type 分类
- trust_level 声明
- capability reference 关联
- adapter reference

## 4. Registry 不负责

禁止演变为：

- SSH 密钥仓库
- 服务器资产管理
- 部署状态数据库
- 工作流调度中心
- 工具市场
- 执行权限系统

## 5. 最小原则

先证明环境身份和能力关联价值，再增加存储、API 或服务化能力。

V0.9-D1 不引入数据库、Web 服务、自动同步或执行能力。
