# Kai V1.1 Capability Provider Roadmap

## Goal

Connect Kai with existing environment capabilities while preserving Control Plane boundaries.

## Boundary

```
Kai
 |
Capability Reference
 |
Capability Provider
 |
Environment
```

## First Prototype

Capability Provider starts with readonly capabilities:

- service status query
- health check query

No restart, deployment, or configuration modification is included initially.

## Forbidden Expansion

Do not introduce:

- Kai Executor
- SSH manager
- workflow engine
- tool marketplace
- autonomous recovery loop

## Evolution

After readonly validation succeeds, controlled actions may be evaluated separately with governance requirements.
