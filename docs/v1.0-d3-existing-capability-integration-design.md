# Kai V1.0-D3 Existing Capability Integration Design

状态：Design

## 目标

验证 Kai 是否可以关联已有执行能力，而不重新实现执行系统。

## 架构

```text
External Agent
      |
      v
Governance Intent
      |
      v
Kai Validator
      |
      v
Capability Reference
      |
      v
Existing Tool / MCP / Service
      |
      v
Environment
      |
      v
Observation Verification
```

## 责任划分

|组件|责任|
|-|-|
|Agent|提出建议|
|Kai|治理检查与证据关联|
|Existing Capability|实际执行|
|Environment|最终安全约束|

## 禁止扩展

不实现：

- Executor
- Workflow
- Shell Gateway
- MCP Server

## VPS 后续验证前提

真实接入需要人工完成 VPS 授权、工具入口确认和安全检查。

在此之前仅保持设计状态。
