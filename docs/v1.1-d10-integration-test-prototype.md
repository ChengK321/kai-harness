# Kai V1.1-D10 Integration Test Prototype

状态：Design Prototype / Readonly Validation

## 目标

验证 Kai 当前只读闭环是否成立：

```text
Environment
    |
    v
Existing Observer
    |
    v
Observation Evidence
    |
    v
Capability Reference
    |
    v
Verification Contract
    |
    v
Verified Result
```

本阶段不验证环境修改能力。

## 测试范围

### 1. Identity Binding

验证 observation 与 environment identity 一致。

错误环境必须返回 deny 或 unknown，不允许继续关联。

### 2. Capability Binding

验证 capability reference 仅引用已登记能力，不包含执行命令或执行入口。

### 3. Evidence Association

验证 provider/observer 输出作为 evidence 被关联，而不是直接作为成功结果。

### 4. Verification

验证 verification contract 可以独立判断结果。

示例：

service active 不自动推导 website healthy。

## 禁止范围

- restart service
- shell execution
- SSH access
- executor
- workflow
- automatic remediation

## 验收标准

通过本阶段后，Kai 具备只读 capability integration 基础，但仍保持 Control Plane 定位。
