# Kai V1.0-D3.2 Existing Capability Integration Design

Status: Design

## Goal

Integrate existing capabilities without creating a Kai Executor.

## Data Flow

```
Agent
 |
 v
Governance Intent
 |
 v
Validator
 |
 v
Capability Reference
 |
 v
Existing Tool / MCP / Service
 |
 v
Environment
 |
 v
Evidence
```

## Kai Responsibility

Kai provides:
- identity binding
- governance validation
- capability reference
- evidence association

## Existing System Responsibility

Existing tool or service provides:
- execution
- native permission checks
- domain safety
- operation result

## Forbidden Expansion

No:
- shell gateway
- universal executor
- tool wrapper duplication
- workflow engine
