# Kai V1.1-D4 Readonly Capability Provider Prototype

## Status

Design prototype.

This stage introduces the first Capability Provider boundary without introducing execution capability.

## Goal

Validate the following chain:

```
Environment
    |
    v
Readonly Capability Provider
    |
    v
Capability Reference
    |
    v
Observation Contract
    |
    v
Verification Result
```

## Supported Capability

V1.1-D4 only supports readonly capabilities:

- service.status.read
- health.check.read

It does not support:

- restart_service
- shell execution
- ssh execution
- configuration mutation

## Boundary

Kai owns:

- capability reference
- governance association
- verification requirement

Provider owns:

- environment query
- domain integration
- evidence generation

Environment owns:

- actual runtime state

## Evidence Model

Provider output is evidence, not a final decision.

Example:

```
service.status.read
        |
        v
nginx = active
        |
        v
verification checks application health separately
```

A running process does not imply business availability.

## Non Goals

This prototype is not:

- an executor
- an automation engine
- a workflow system
- an auto recovery service
