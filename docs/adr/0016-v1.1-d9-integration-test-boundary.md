# ADR-0016 V1.1-D9 Integration Test Boundary

Status: Proposed

## Context

V1.1 introduces Capability Adapter concepts. The main risk is accidentally turning the adapter into an executor.

## Decision

Integration tests only validate information flow:

- observation collection
- capability reference binding
- verification result generation

They do not validate environment modification.

## Accepted

- Readonly capability flow
- Evidence association
- Verification contract checks

## Rejected

- Direct command execution
- Service restart tests
- Generic executor abstraction
- Workflow engine introduction

## Consequence

V1.1 remains a controlled read-only integration prototype.
Real action capability requires a separate architecture review.
