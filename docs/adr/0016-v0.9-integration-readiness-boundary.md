# ADR-0016 V0.9 Integration Readiness Boundary

状态：V0.9 文档冻结基线 / 待人工审核；不构成部署或执行授权。

## Context

仓库已有分散的 V0.9 环境、Observation、Capability 设计及内存 Registry 原型，
但缺少 docs/v0.9/ 版本化总览和就绪结论。文档恢复必须记录真实实现状态，
不能把设计存在误写为环境已接通。

## Decision

V0.9 定位为 Environment Integration Readiness 的职责整合，不是执行扩张。
Observation 提供只读证据，Capability 描述能力引用，Governance 定义授权边界。
三者依赖明确环境身份，均不因元数据关联而获得执行权限。

复用外部 Agent SDK / Harness、MCP、OpenTelemetry、ROS2；
Kai 不成为 Agent Framework、Workflow Engine、Executor、Telemetry Platform 或 Robot Controller。
文档冻结与实现就绪分开报告：当前真实执行仍未就绪且不在本阶段范围。

## Consequences

优点：版本资料可追溯，保留历史资产，明确设计、原型与生产集成的区别。
限制：身份认证、证据可信性、Capability 可用性、审批核验和运行安全不能由文档证明。
execution_enabled=false、require_tool_executor=true 保持有效；任何迁移需独立审核。

## Rejected Alternatives

- 将文档补齐视为真实集成已完成：缺少调用、身份绑定和运行证据。
- 为补齐架构图新增 Executor 或自动连接：超出 Control Plane 职责和本次授权。
- 重写或删除历史设计：丢失演进依据，也会混淆冻结契约与新提案。
