# ADR-0017 V1.0 Observation Governance Boundary

状态：Proposed

## Context

V1.0 需要验证 Kai Control Plane 是否可以关联环境事实与治理约束。

## Decision

Observation 与 Governance 保持独立职责。

```text
Observation
    |
    v
Evidence Reference
    |
    v
Governance Intent
    |
    v
Validation
```

Observation 提供证据，Governance 验证约束。

二者均不拥有决策和执行能力。

## Consequences

优点：

- 保持 Kai 薄控制面定位；
- 避免 Observation 演化为自动修复系统；
- 避免 Governance 演化为 Workflow Engine。

限制：

- Agent 仍需要外部推理能力；
- 执行能力仍由 Existing Tool 或 Environment Service 提供。

## Rejected Alternatives

拒绝：

1. Observation 直接触发 Action。
2. Validator 内置修复流程。
3. Kai 管理完整执行生命周期。
