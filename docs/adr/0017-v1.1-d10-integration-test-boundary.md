# ADR-0017 V1.1-D10 Integration Test Boundary

状态：Proposed

## Context

V1.1 目标是验证 Capability Reference、Observation 和 Verification 的组合，而不是建设执行平台。

## Decision

采用只读集成验证：

```text
Observer
   |
   v
Capability Reference
   |
   v
Verification
```

不引入新的执行抽象。

## Accepted

- readonly capability
- evidence association
- verification result

## Rejected

- executor
- command runner
- SSH bridge
- workflow engine
- automatic repair

## Consequence

Kai 保持 AI Control Plane 边界，真实环境操作仍由外部受信能力负责。
