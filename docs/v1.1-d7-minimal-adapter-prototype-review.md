# Kai V1.1-D7 Minimal Capability Adapter Prototype Review

Status: Proposed / Design Review

## Purpose

D7 reviews whether Kai needs a new Capability Provider implementation or whether existing Observation components can satisfy the first controlled prototype.

## Conclusion

Do not create a new Provider Framework.

The first V1.1 prototype should reuse existing observation capabilities and introduce only a minimal adapter boundary.

## Adapter Responsibility

The adapter only translates existing facts into capability-oriented references.

Allowed:

- map observation output to capability evidence;
- provide stable capability identifiers;
- attach verification requirements.

Not allowed:

- execute commands;
- manage SSH sessions;
- restart services;
- implement workflows.

## Decision

Proceed with a minimal adapter prototype before any action capability.

The first capability remains read-only:

- service.status.read
- health.check.read

Write operations require a separate ADR.
