# Kai V1.1-D6 Minimal Capability Adapter Design

Status: Proposed / Design Only

## 1. Purpose

V1.1-D6 defines the smallest integration boundary between existing observation capability and Kai capability governance.

The goal is not to create a new Provider framework, but to reuse existing observation components and expose a governed capability reference.

## 2. Boundary

```
Environment
    |
    v
Existing Observer (vps-observer / kai-observation)
    |
    v
Minimal Capability Adapter
    |
    v
Capability Reference
    |
    v
Kai Governance + Verification
```

## 3. Adapter Responsibility

The adapter may:

- map existing observation output to capability evidence;
- expose readonly capability metadata;
- associate verification contracts.

The adapter does not:

- execute commands;
- restart services;
- manage SSH credentials;
- run workflows;
- decide remediation actions.

## 4. First Capability

Initial capability:

```
service.status.read
```

Example evidence:

```
service: nginx
state: active
source: existing observer
```

## 5. Design Principle

Capability reference describes what an environment can provide. It does not grant Kai execution authority.

Execution remains owned by external capability providers or environment systems.
