# Kai V1.0-D3.3 Integration Boundary Review

Status: Design Review

## Review Result

D3 integration keeps the original Control Plane boundary.

## Accepted

- Observation provides facts.
- Governance validates constraints.
- Capability references existing abilities.
- External systems execute operations.

## Rejected

The following are not part of Kai:

- Agent loop
- Planner
- Executor
- Workflow orchestration
- Robot controller
- Automatic remediation

## Final Integration Model
