# Kai V1.0-D4.0 Verification Loop Design

Status: Design

## Objective

Verify that controlled operations achieve the intended environment outcome.

## Flow

```
Observation
    |
    v
Governance Intent
    |
    v
Validation
    |
    v
Existing Capability
    |
    v
Execution Evidence
    |
    v
Observation Verification
    |
    v
Final Result
```

## Key Principle

Execution accepted != Goal achieved.

Example:

restart nginx accepted

is different from:

website recovered.

## Verification Responsibilities

Kai:
- references verification requirements
- associates evidence

Environment:
- provides real state
- performs domain checks

## Current Status

D4 remains prototype design until real VPS validation is performed.
