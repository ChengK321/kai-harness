# Kai V0.9-D2.2 Observation Provider Registration Metadata

Status: Design Only

## Purpose

Define the smallest metadata boundary between Environment Registry and Observation Provider. This is not a plugin system, marketplace, or discovery service.

## Data Flow

```text
Environment Registry
        |
        | references trusted provider metadata
        v
Observation Provider
        |
        v
Observation Contract
```

## Provider Metadata Scope

Allowed:

- provider_id
- provider_type
- contract_version
- supported_environment_types
- readonly capability declaration

Not included:

- credentials
- execution commands
- deployment information
- runtime scheduling
- health monitoring backend

## Boundary Decision

Provider metadata describes how observations can be produced. It does not grant execution permission and does not establish identity authority.

Execution authorization remains under Governance and existing environment systems.
