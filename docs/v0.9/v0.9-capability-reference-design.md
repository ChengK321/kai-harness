# Kai V0.9 Capability Reference Design

**Capability = 能力引用。** 描述环境可声明关联的外部能力，不拥有调用实现。

```text
Environment Registry
        |
Capability Reference
        |
Existing MCP Tool / Domain API / ROS2 Service
```

连线只表示引用关系，不是当前执行链。沿用现有模型，元数据可包含 capability_id、
capability_type、environment_binding、provider_reference、contract_version 和只读属性。
V0.9 不新增 Schema、能力清单或自动加载机制。

## 与 Observation / Governance 的关系

Observation 提供只读证据；Capability 标识可能关联的能力；Governance 定义授权边界。
三者相互引用不构成执行许可。离线 Validator 的 allow 只证明所覆盖的结构检查通过，
未核验 Capability 登记、真实审批或环境运行安全。

已有 Tool 满足参数与治理需要时直接复用其契约；不要复制为同名 Action Tool。
MCP 是外部能力交互选择，ROS2 是未来机器人领域接口选择；两者都不由 Kai 替代。

## 禁止吸收的职责

引用中不包含 shell、命令模板、执行工作流、retry、Planner、模型 prompt 或凭据。
不建立 Marketplace、插件安装器、通用 Dispatcher 或 Executor Registry。
能力存在、已登记、可用、获准使用是不同事实，不能仅凭 capability 字符串相互推导。

当前原型只有 capability 字符串声明和查询；完整 Provider、契约及受信身份映射尚未接通。
先证明单一场景的引用价值，再考虑版本化字段，不为了未来通用性提前扩张。
