# Kai V0.9 Freeze Summary

日期：2026-09-18。
冻结范围：**文档与职责边界基线**；实现和部署状态以
[Readiness Review](v0.9-integration-readiness-review.md) 为准。
该冻结不代表代码发布、生产验收、历史 ADR 自动获批或真实执行授权。

## 冻结的原则

- Kai 是 AI Control Plane，不是 Agent Framework、Workflow Engine、Executor、
  Telemetry Platform 或 Robot Controller。
- Observation 是只读证据；Capability 是能力引用；Governance 是授权边界。
- Registry 登记不是连接或授权；Capability 声明不是可执行许可。
- Governance Intent 不可执行，离线 allow 不代表真实授权或目标达成。
- 复用 Agent SDK、MCP、OpenTelemetry 和 ROS2 生态，不重新拥有其运行、遥测或控制职责。
- V0.6–V0.8 契约和历史设计保留，不修改执行开关或旧安全约束。

## 冻结后的变更规则

新字段应证明具体身份、证据或治理关联需求；职责扩张必须先审 ADR。
不得把关联元数据演变为工具调用协议、自动修复计划或工作流状态机。
下一阶段优先离线验证身份与引用一致性，执行接入继续保持阻断。
