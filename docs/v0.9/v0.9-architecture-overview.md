# Kai V0.9 Architecture Overview

## 演进关系

```text
V0.6 Control Plane
  薄 Harness，复用外部 Agent Runtime
           |
           v
V0.7 Observation
  只读采集 → Contract → Provider
           |
           v
V0.8 Governance Boundary
  声明式 Intent → 离线校验 → 检查报告
           |
           v
V0.9 Environment Integration Readiness
  环境身份 + Observation 证据引用 + Capability 引用
  冻结集成边界，不新增执行能力
```

V0.5 冻结契约保留为基础资产。V0.9 不恢复自研 Runtime、Memory 或 Tool Executor 路线。

## 当前整体架构

```text
External Agent
       |
Kai Control Plane
       |
+----------------+
| Observation    |
| Capability     |
| Governance     |
+----------------+
       |
Environment
```

这是逻辑职责图，不表示所有链路已连接。Environment Registry 为三者提供环境身份和声明引用；
实际观察数据由 Environment 经 Adapter/Provider 返回控制面，图中竖线不授予环境写权限。

| 边界 | 定义 | 当前限制 |
| --- | --- | --- |
| Observation | 只读证据 | 有 Provider 与 VPS 只读原型；证据关联仍为设计。 |
| Capability | 能力引用 | 已有声明与模型文档，不是工具调用系统。 |
| Governance | 授权边界 | 已有声明契约与离线校验；不等于真实授权系统。 |

Kai 不是 **Agent Framework、Workflow Engine、Executor、Telemetry Platform、Robot Controller**。
当前 Runner 委托 Claude Code；Observation Provider 尚未由 Runner 自动调用。
Registry 原型的存在不证明身份已认证或集成已完成。

## 生态关系

下列是 Kai 的集成职责选择，不表示已安装或连接这些系统：

| 生态 | Kai 的关系 | 不承担的职责 |
| --- | --- | --- |
| Agent SDK / 外部 Harness | 复用推理、Agent loop 和工具使用能力；Kai 限定接入边界 | 不重建 Agent Framework 或 Planner。 |
| MCP | 引用已有 Tool/Resource 能力；需要时关联治理记录 | 不改 MCP 接口，不另造工具协议或客户端运行时。 |
| OpenTelemetry | 可复用外部遥测来源及关联标识，提取所需只读证据 | 不建遥测后端、时序库、告警或监控平台。 |
| ROS2 | 将来引用领域能力和只读状态，由专业环境承载控制 | 不重建 topic/service/action，不实现轨迹、碰撞算法或实时控制。 |

具体关系沿用 [架构边界矩阵](../architecture-boundary-matrix.md)。
本次没有新增任何执行能力，也没有把生态引用变成接入授权。
