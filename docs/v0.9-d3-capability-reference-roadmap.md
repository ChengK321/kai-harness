# Kai V0.9-D3 Capability Reference Integration Roadmap

## Objective

Integrate existing capabilities without creating a new tool protocol or executor.

## Boundary

```
Governance Intent
        |
        v
Capability Reference
        |
        v
Existing MCP / Tool / Domain Service
        |
        v
Environment
```

## D3 Stages

### D3.1 Capability Model

Define minimal capability identity and reference metadata.

### D3.2 Registry Mapping

Associate environments with declared capabilities.

### D3.3 Tool Boundary Alignment

Reuse existing MCP and tools instead of wrapping them again.

### D3.4 Governance Binding

Associate capability usage with intent, approval and verification references.

## Non Goals

Capability Reference is not:

- tool marketplace
- executor
- workflow engine
- deployment system

## Review Gate

If a capability requires Kai to execute commands, schedule tasks or own domain logic, stop and review architecture.
