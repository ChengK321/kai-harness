# Kai V0.9-D3.2 Capability Registry Mapping Design

Status: Proposed

## Purpose

Capability Reference connects Environment Registry with existing capabilities. It does not create a tool marketplace or executor registry.

## Model

Environment
  |
  +-- Capability Reference
          |
          +-- provider reference
          +-- contract version
          +-- capability metadata

## Boundary

Registry stores identity and references. Existing tools own execution.

Not included:
- execution
- scheduling
- installation
- secrets
- permission issuing
