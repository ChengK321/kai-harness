# Kai V0.9-D4 Ecosystem Alignment

## External Ecosystem Position

Kai does not replace existing ecosystems.

| Capability | Owner |
|---|---|
| Agent reasoning | Agent SDK / external agent |
| Tool protocol | MCP / existing APIs |
| Telemetry | OpenTelemetry and monitoring systems |
| Robot control | ROS2 and robot controllers |
| Governance boundary | Kai |

## Integration Principle

Reuse mature execution systems. Kai only adds identity, governance, evidence and references.
