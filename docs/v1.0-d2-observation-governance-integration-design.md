# Kai V1.0-D2 Observation / Governance Integration Design

状态：Design baseline

## 1. 目标

V1.0-D2 验证 Observation 与 Governance 是否可以形成安全闭环，但不引入自动决策和执行能力。

核心链路：

```text
Environment
    |
    v
Observation Provider
    |
    v
Observation Evidence
    |
    v
External Agent Reasoning
    |
    v
Governance Intent
    |
    v
Governance Validator
```

## 2. 边界

Observation 负责提供事实：

- 环境状态
- 时间戳
- 来源
- 证据引用

Observation 不负责：

- 判断故障原因
- 生成修复方案
- 自动触发动作

Governance 负责：

- 校验主体
- 校验环境绑定
- 校验能力引用
- 校验风险约束
- 关联验证条件

Governance 不负责：

- 任务规划
- 执行操作
- 自动恢复

## 3. Evidence Reference

示例：

```json
{
  "evidence_id": "obs-vps-001",
  "environment_id": "vps-demo",
  "provider": "vps-observer",
  "timestamp": "2026-01-01T00:00:00Z"
}
```

Evidence Reference 不是遥测数据库，不复制完整 Observation 数据。

## 4. Intent 关联

Governance Intent 可以引用 Observation Evidence：

```text
Observation Evidence
        |
        v
Governance Intent
        |
        v
Validation
```

引用关系用于证明请求基于已知事实，不代表 Agent 决策正确。

## 5. 禁止扩展

禁止：

- Observation 自动生成 Action
- Validator 自动修复
- Kai 自研 Workflow
- Kai 自研 Executor

V1.0-D2 保持 Control Plane 定位。
